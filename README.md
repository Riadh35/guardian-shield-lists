# Guardian Wall — listes de menaces

Listes signées utilisées par l'extension Guardian Wall – Anti-arnaque & Anti-phishing.
Construites toutes les heures à partir de Phishing.Database (MIT), de phishunt.io (CC0 1.0) et du Chrome UX Report (CC BY 4.0).
Les fichiers publiés (branche `lists`) ne contiennent que des empreintes, pas d'adresses en clair.
